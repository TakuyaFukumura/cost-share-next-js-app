# ボーナス用計算ページ 検討資料

## 1. 目的

夫婦それぞれのボーナス手取り額と、世帯で決めた貯金目標額を入力し、目標額を負担割合に応じて夫婦で拠出した場合の負担額と拠出後の残額を確認できるページを追加する。

月々の共通予算ではなく、ボーナスから貯金に回す金額を計算する。入力値を変更すると結果がすぐに更新される想定。

## 2. 想定する画面

- URL は `/bonus` とする案。
- 既存の月次計算ページとは独立した画面とし、ヘッダーから相互に移動できるようにする。
- 入力項目：
  - 夫のボーナス手取り額
  - 妻のボーナス手取り額
  - 世帯の貯金目標額
- 計算結果：
  - 夫婦それぞれの負担割合
  - 夫婦それぞれの貯金拠出額
  - 拠出後のボーナス残額
  - 世帯の拠出額合計と拠出後残額合計

## 3. 計算案

負担割合は入力されたボーナス手取り額の比率とする。実際の拠出総額は貯金目標額とボーナス合計のうち少ない方とし、この金額を負担割合で分ける。夫の拠出額を円単位で四捨五入し、妻の拠出額は実際の拠出総額から夫の拠出額を引いて求める。

```
ボーナス合計 = 夫のボーナス手取り額 + 妻のボーナス手取り額
夫の負担割合 = 夫のボーナス手取り額 ÷ ボーナス合計
妻の負担割合 = 妻のボーナス手取り額 ÷ ボーナス合計

実際の拠出総額 = 貯金目標額とボーナス合計のうち少ない方
夫の拠出額 = 実際の拠出総額 × 夫の負担割合（円単位で四捨五入）
妻の拠出額 = 実際の拠出総額 - 夫の拠出額
未達額 = 貯金目標額 - 実際の拠出総額

夫の拠出後残額 = 夫のボーナス手取り額 - 夫の拠出額
妻の拠出後残額 = 妻のボーナス手取り額 - 妻の拠出額
世帯の拠出後残額 = ボーナス合計 - 実際の拠出総額
```

貯金目標額がボーナス合計を上回る場合、夫婦はボーナス全額を拠出し、差額を未達額として表示する。拠出後の残額はマイナスにならない。

## 4. 初期値の案

動作イメージを確認するための仮の初期値。将来的に利用者が自由に変更でき、初期値は仕様確定時に調整できる。

| 入力 | 仮の初期値 |
| --- | ---: |
| 夫のボーナス手取り額 | 500,000円 |
| 妻のボーナス手取り額 | 400,000円 |
| 貯金目標額 | 300,000円 |

この例では、夫の負担割合は約55.6%、妻は約44.4%となり、拠出額は夫166,667円、妻133,333円。拠出後残額は夫333,333円、妻266,667円となる。

## 5. 入力・例外ケース案

- 金額は円単位の数値で入力し、0円未満は受け付けない。
- 夫婦のボーナス合計が0円の場合は、負担割合と拠出額を0円とする。貯金目標額は全額未達として表示する。
- 片方のボーナスだけが0円の場合、もう片方の負担割合を100%とする。
- 貯金目標額が0円の場合、拠出額は両者とも0円とする。
- ボーナス合計が貯金目標額を下回る場合は、ボーナス合計を拠出し、目標との差額を未達額として表示する。
- 負担割合は表示上小数第1位までとし、計算は入力金額から求めた丸め前の割合を使用する。
- 入力欄を空にした際の一時状態と、その場合の計算表示は実装時に既存ページの入力挙動と揃える。

## 6. 既存ページとの関係

- 月次の負担割合計算は現状どおりとし、ボーナス計算は別ページとして追加する。
- 月次計算で利用している CSV の共通予算や初期月収は、ボーナス計算には使用しない。
- 画面デザイン、通貨表示、ダークモード、負数の強調表示は既存ページに合わせる。
- ページ追加時には、ヘッダーのナビゲーション、関連するテスト、`docs/家計負担割合_仕様解説書.md` のページ説明を更新する。

## 7. 対話で決定した事項

- 負担割合は月収ではなく、夫婦それぞれのボーナス手取り額の比率で計算する。
- 貯金目標額がボーナス合計を超える場合は、ボーナス合計を拠出上限とし、目標との差額を未達額として表示する。
- 夫婦のボーナスがどちらも0円の場合は、負担割合を0%ずつ、拠出額を0円ずつとし、貯金目標の全額を未達として表示する。

## 8. 実装時に決める点

初期値は現時点では夫500,000円、妻400,000円、貯金目標300,000円の仮設定とする。目標未達時は、未達額を注意色のステータス表示で強調する。
