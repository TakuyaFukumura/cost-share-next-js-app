# 家計負担割合計算アプリ 仕様解説書

## 1. このアプリの目的

夫婦それぞれの当月手取り収入に応じて、家計の共通予算をどの割合で負担するかを計算するアプリです。

「収入が多い人が多く負担する」という完全収入比例の考え方を採用しています。収入の入力を変更すると、負担割合・拠出額・拠出後の残額がすぐに更新されます。
食費については食事量の差を考慮し、夫婦それぞれの負担割合を個別に設定できます。

## 2. 計算に使うデータ

共通予算と初期表示する収入は、`public/data/budget_data.csv` に登録されています。

| データ | 条件 | 用途 |
| --- | --- | --- |
| 共通予算 | `is_active` が `true` の行 | 共通予算の項目と合計額 |
| 夫の初期収入 | `category` が `income_sample` かつ項目名に「夫」を含む行 | 夫の入力欄の初期値 |
| 妻の初期収入 | `category` が `income_sample` かつ項目名に「妻」を含む行 | 妻の入力欄の初期値 |

現在の共通予算は次のとおりです。

- 家賃：150,000円
- 光熱費：20,000円
- 通信費（Wi-Fi）：5,000円
- 水道代：3,000円
- 食費：50,000円
- 日用品：10,000円
- 共通貯金：30,000円
- 投資（NISA）：100,000円
- 合計：358,000円

初期収入は、夫・妻ともに230,000円です。CSVの金額が読み取れない場合、その金額は0円として扱われます。

## 3. 計算の流れ

### 3.1 合計収入

まず、入力された夫と妻の収入を合計します。

```
合計収入 = 夫の収入 + 妻の収入
```

入力欄は0円未満にならないように制限されています。

### 3.2 負担割合

合計収入に占めるそれぞれの収入の割合を、そのまま負担割合にします。

```
夫の負担割合 = 夫の収入 ÷ 合計収入
妻の負担割合 = 妻の収入 ÷ 合計収入
```

画面では割合をパーセントに変換し、小数第2位を四捨五入して小数第1位まで表示します。

### 3.3 拠出額

食費以外は収入による負担割合を適用し、食費には画面で設定した男女差係数を適用して各自の拠出額を求めます。夫の拠出額は円単位で四捨五入します。妻の拠出額は、共通予算の合計から夫の拠出額を引いて求めるため、2人の拠出額の合計は必ず共通予算と一致します。

```
夫の拠出額 = （共通予算合計 - 食費）× 夫の負担割合
           + 食費 × 男性の食費負担割合（円単位で四捨五入）
妻の拠出額 = 共通予算合計 - 夫の拠出額
```

食費の負担割合は初期値を男性55%、女性45%とし、画面から変更できます。2つの割合の合計は常に100%です。

### 3.4 拠出後の残額

収入から拠出額を引いた金額を、拠出後の残額として表示します。

```
夫の残額 = 夫の収入 - 夫の拠出額
妻の残額 = 妻の収入 - 妻の拠出額
合計差額 = 合計収入 - 共通予算合計
```

残額がマイナスの場合は、画面上で赤字表示になります。これは収入だけでは担当分の拠出額をまかなえない状態を示します。

## 4. 初期値での計算例

夫と妻の収入がともに230,000円で、食費の負担割合が男性55%、女性45%の場合の例です。

| 項目 | 夫 | 妻 |
| --- | ---: | ---: |
| 収入 | 230,000円 | 230,000円 |
| 収入による負担割合 | 50.0% | 50.0% |
| 食費の負担割合 | 55.0% | 45.0% |
| 拠出額 | 181,500円 | 176,500円 |
| 拠出後の残額 | 48,500円 | 53,500円 |

合計差額は、合計収入460,000円から共通予算358,000円を引いた102,000円です。

## 5. 例外的な入力の扱い

- 夫婦の合計収入が0円以下の場合、割合・拠出額・残額はすべて0円として表示します。0円で割る計算を行わないためです。
- 片方だけが収入を入力した場合、その人の負担割合は100.0%、もう片方は0.0%になります。
- 共通予算より収入合計が少ない場合でも計算は行われ、拠出後の残額がマイナスになることがあります。

## 6. 画面の見方

1. **収入入力フォーム**：夫と妻の当月手取り収入を入力します。合計収入も表示されます。
2. **共通予算サマリ**：CSVで有効になっている共通予算の項目と合計を表示します。
3. **計算結果**：夫婦それぞれの負担割合と拠出額を表示します。
4. **差額サマリ**：拠出後にそれぞれの手元に残る金額と、世帯全体の差額を表示します。
5. **食費の負担割合**：食費に適用する男性・女性の負担割合を入力します。変更すると拠出額と残額が更新されます。

## 7. 共通予算を変更する場合

`public/data/budget_data.csv` の共通予算行を変更します。金額は `amount` 列に円単位で入力し、計算対象に含める行は `is_active` を `true` にします。`false` の行は一覧にも合計にも含まれません。

変更後に画面を再読み込みすると、サーバーがCSVを読み込み直して新しい予算で計算します。
