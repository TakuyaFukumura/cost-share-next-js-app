# 家計負担割合計算アプリ 仕様解説書

## 1. このアプリの目的

夫婦それぞれの当月手取り収入に応じて、家計の共通予算をどの割合で負担するかを計算するアプリです。

「収入が多い人が多く負担する」という完全収入比例の考え方を採用しています。収入の入力を変更すると、負担割合・支出・支出後の残額がすぐに更新されます。

## 2. 計算に使うデータ

共通予算と初期表示する収入は、`public/data/budget_data.csv` に登録されています。

| データ | 条件 | 用途 |
| --- | --- | --- |
| 共通予算 | `is_active` が `true` の行 | 共通予算の項目と合計額 |
| 夫の初期収入 | `category` が `income_sample` かつ項目名に「夫」を含む行 | 夫の入力欄の初期値 |
| 妻の初期収入 | `category` が `income_sample` かつ項目名に「妻」を含む行 | 妻の入力欄の初期値 |

現在の共通予算は次のとおりです。

- 家賃：90,000円
- 光熱費：20,000円
- Wi-Fi：5,000円
- 水道代：4,000円
- 食費：60,000円
- 日用品：10,000円
- 資産形成：100,000円
- 予備費：10,000円
- 合計：299,000円

初期収入は、夫が240,000円、妻が210,000円です。CSVの金額が読み取れない場合、その金額は0円として扱われます。

## 3. 計算の流れ

### 3.1 合計収入

まず、入力された夫と妻の収入を合計します。

```
合計収入 = 夫の収入 + 妻の収入
```

入力欄は0円未満にならないように制限されています。

### 3.2 負担割合

合計収入に占めるそれぞれの収入の割合を、そのまま負担割合にします。

```
夫の負担割合 = 夫の収入 ÷ 合計収入
妻の負担割合 = 妻の収入 ÷ 合計収入
```

画面では割合をパーセントに変換し、小数第2位を四捨五入して小数第1位まで表示します。

### 3.3 支出

共通予算全体に収入による負担割合を適用します。夫の支出は円単位で四捨五入します。妻の支出は、共通予算の合計から夫の支出を引いて求めるため、2人の支出の合計は必ず共通予算と一致します。

```
夫の支出 = 共通予算合計 × 夫の負担割合（円単位で四捨五入）
妻の支出 = 共通予算合計 - 夫の支出
```

### 3.4 拠出後の残額

収入から支出を引いた金額を、支出後の残額として表示します。

```
夫の残額 = 夫の収入 - 夫の支出
妻の残額 = 妻の収入 - 妻の支出
合計 = 合計収入 - 共通予算合計
```

残額がマイナスの場合は、画面上で赤字表示になります。これは収入だけでは担当分の支出をまかなえない状態を示します。

## 4. 初期値での計算例

夫と妻の収入がともに230,000円で、現在の共通予算299,000円を負担する場合の例です。

| 項目 | 夫 | 妻 |
| --- | ---: | ---: |
| 収入 | 230,000円 | 230,000円 |
| 収入による負担割合 | 50.0% | 50.0% |
| 支出 | 149,500円 | 149,500円 |
| 拠出後の残額 | 80,500円 | 80,500円 |

合計は、合計収入460,000円から共通予算299,000円を引いた161,000円です。

## 5. 例外的な入力の扱い

- 夫婦の合計収入が0円以下の場合、割合・支出・残額はすべて0円として表示します。0円で割る計算を行わないためです。
- 片方だけが収入を入力した場合、その人の負担割合は100.0%、もう片方は0.0%になります。
- 共通予算より収入合計が少ない場合でも計算は行われ、拠出後の残額がマイナスになることがあります。

## 6. 画面の見方

1. **手取り月収**：夫と妻の手取り月収を入力します。合計も表示されます。
2. **共通予算**：CSVで有効になっている共通予算の項目と合計を表示します。各項目の金額は画面から編集でき、変更内容は合計と計算結果へ即時反映されます。
3. **計算結果**：夫婦それぞれの負担割合と支出を表示します。
4. **収支**：支出後にそれぞれの手元に残る金額と、世帯全体の差額を表示します。
## 7. 共通予算を変更する場合

初期値を変更する場合は `public/data/budget_data.csv` の共通予算行を変更します。金額は `amount` 列に円単位で入力し、計算対象に含める行は `is_active` を `true` にします。`false` の行は一覧にも合計にも含まれません。画面上での金額変更は、その画面を表示している間だけ有効です。

CSVを変更した後に画面を再読み込みすると、サーバーがCSVを読み込み直して新しい予算で計算します。

## 8. 家賃補助がある場合の考え方

家賃補助を受給者の給与や福利厚生として扱うかによって、夫婦間の公平な負担割合は変わります。補助を家賃から先に差し引き、残った金額だけを折半すると、補助の恩恵と、補助が課税対象になる場合の税金・社会保険料の負担が受給者側に偏る可能性があります。

公平性を重視する場合は、次のいずれかの方法を夫婦で合意します。

- 補助込みの手取り収入を基準に負担割合を計算する
- 補助の手取り相当額を共通家計の利益として扱う
- 補助を受給者個人の福利厚生とみなし、補助後の家賃を折半する

家賃補助が課税対象になるか、社会保険料の算定に含まれるかは、支給方法や勤務先の制度によって異なります。詳しい考え方は、アプリのヘッダーにある「解説」から「家賃補助を受ける場合の考え方」を選んでください。

## 9. 解説ページ

ヘッダーの「解説」リンクから、解説一覧（`/explanation`）を開きます。一覧から次の記事を選べます。

- **計算のしくみ**（`/explanation/calculation`）：収入割合、共通予算の分担、端数処理、拠出後の残額をフローチャートと式で説明します。合計収入が0円の場合などの例外は注記します。
- **家賃補助を受ける場合の考え方**（`/explanation/rent-subsidy`）：家賃補助を受ける場合の公平性と、代表的な考え方を説明します。

各記事から解説一覧へ戻ることができ、一覧から計算ページへ移動できます。

## 10. ボーナス貯金計算ページ

ヘッダーの「ボーナス計算」リンクから、ボーナス貯金計算ページ（`/bonus`）を開きます。夫婦それぞれのボーナス手取り額と、世帯の貯金目標額を入力すると、負担割合・拠出額・拠出後の残額が即時に更新されます。貯金目標額は万円単位で入力し、計算時に円へ換算します。初期値は夫100,000円、妻500,000円、貯金目標額30万円（300,000円）です。

負担割合は、夫婦のボーナス手取り額合計に占めるそれぞれの割合です。貯金目標額がボーナス合計以下の場合は目標額を按分し、夫の拠出額を円単位で四捨五入、妻の拠出額を目標額から夫の拠出額を引いて計算します。貯金目標額がボーナス合計を超える場合は、ボーナス合計を拠出上限とし、目標との差額を注意色のステータス表示で未達額として示します。

夫婦のボーナス合計が0円の場合は負担割合と拠出額を0円とし、貯金目標額の全額を未達として表示します。片方のみボーナスがある場合、その人の負担割合を100%とします。
