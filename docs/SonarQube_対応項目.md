# SonarQube 対応項目

## 対象

2026年9月25日に実施した SonarQube Community Build `26.9.0.129388` の解析結果から、動的な画面更新のアクセシビリティに関わる指摘を対応対象として選定しました。バグと脆弱性は検出されていません。

## 対応する指摘

| 重要度・優先度 | ファイル・行 | 内容 |
| --- | --- | --- |
| Major・要対応 | `src/app/components/BonusCalculator.tsx:91` | 動的な未達額の通知に `<p role="status">` を使っています。SonarQube は計算結果を表す `<output>` 要素の使用を推奨しています。 |

未達額は入力値に応じて変化する計算結果です。`<output>` を使う形に見直し、未達額が更新されたときに支援技術へ通知される現在の動作を維持してください。変更後は、未達額がある場合とない場合の表示、および読み上げが適切であることを確認します。

## 今回は対応対象外

- Node.js 標準モジュールの import に `node:` プレフィックスを付ける指摘は、書式の統一に関する提案であり、現状の動作上の問題は確認されていないため対象外とします。
- JSX 内の `span` / `strong` 前後の空白に関する指摘は、日本語表示で意図しない空白が発生していることを確認できていないため、必須修正には含めません。画面確認で表示崩れが見つかった場合に限り対応します。

この一覧は対応優先度を選別したものであり、アプリのコード自体は変更していません。SonarQube の全指摘と解析数値は `docs/SonarQube_静的解析.md` を参照してください。
