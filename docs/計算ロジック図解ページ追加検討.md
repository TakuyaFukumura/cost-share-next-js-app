# 計算ロジック図解ページ追加検討

## 1. 背景と目的

現在の「解説」ページ（`/explanation`）は家賃補助を受ける場合の考え方を説明している。一方、計算ページでは、入力した収入や食費の負担割合が、各自の支出と残額にどう反映されるかを段階的に確認しにくい。また、解説が増えた際に、個別のページへ直接遷移するだけでは解説全体を見渡しにくくなる。

解説の一覧ページを設け、一覧から各解説を選べる構成にする。計算ページの仕組みを図と具体例で説明する記事を追加し、利用者が計算結果の根拠を把握できるようにする。家賃補助の解説とは目的を分け、計算式、計算順序、端数処理、例外条件を中心に扱う。

## 2. ページ構成案

- ヘッダーの「解説」リンクは解説一覧（`/explanation`）へ遷移させる。
- 一覧から、個別の解説記事を選べるようにする。
- 計算ロジック図解記事のパス案：`/explanation/calculation`
- 家賃補助記事のパス案：`/explanation/rent-subsidy`
- 現在 `/explanation` にある家賃補助の内容は、家賃補助記事へ移す。
- 各記事の末尾には解説一覧へ戻るリンクを置く。一覧から計算ページへ戻れる導線も用意する。

### 一覧ページの掲載項目案

一覧には、各記事のタイトルと短い説明をカードまたはリストで表示する。

| 記事 | 説明 |
| --- | --- |
| 計算のしくみ | 収入・共通予算・食費負担割合から、支出と残額が決まる流れを図解する。 |
| 家賃補助を受ける場合の考え方 | 家賃補助を家計負担へどう反映するか、代表的な考え方を説明する。 |

## 3. 図解する計算の流れ

ページ上では、次の順序を矢印または番号付きステップで示す。

1. **収入を入力する**：夫・妻それぞれの手取り月収を使う。
2. **合計収入を求める**：夫の収入と妻の収入を足す。
3. **収入に応じた負担割合を求める**：各自の収入を合計収入で割る。
4. **共通予算を分けて支出を求める**：食費以外は収入による負担割合、食費は設定した食費負担割合で分担する。
5. **円単位に丸め、合計を合わせる**：夫の支出を四捨五入し、妻の支出は共通予算合計から夫の支出を引く。
6. **収入から支出を引く**：各自の拠出後の残額と世帯全体の残額を表示する。

### 計算式

```text
合計収入 = 夫の収入 + 妻の収入

夫の負担割合 = 夫の収入 ÷ 合計収入
妻の負担割合 = 妻の収入 ÷ 合計収入

食費以外の予算 = 共通予算合計 - 食費
夫の支出 = round(食費以外の予算 × 夫の負担割合
                  + 食費 × 夫の食費負担割合)
妻の支出 = 共通予算合計 - 夫の支出

夫の残額 = 夫の収入 - 夫の支出
妻の残額 = 妻の収入 - 妻の支出
世帯全体の残額 = 合計収入 - 共通予算合計
```

ここで `round` は円単位の四捨五入を表す。妻の食費負担割合は、夫の割合を100%から引いた値となる。現在の計算ロジックでは、食費以外の予算を収入比で分け、食費だけを指定割合で分ける。

## 4. 掲載する具体例案

現在の初期値に合わせ、次の例を図中またはフロー直下に掲載する。

- 夫の収入：230,000円
- 妻の収入：230,000円
- 共通予算：339,000円
- 食費：60,000円
- 食費負担割合：夫55%、妻45%

| 項目 | 夫 | 妻 |
| --- | ---: | ---: |
| 収入 | 230,000円 | 230,000円 |
| 収入による負担割合 | 50.0% | 50.0% |
| 食費負担割合 | 55.0% | 45.0% |
| 支出 | 172,500円 | 166,500円 |
| 拠出後の残額 | 57,500円 | 63,500円 |

食費以外の予算279,000円を収入比で分けると各139,500円となる。夫の食費負担は33,000円、妻は27,000円なので、支出はそれぞれ172,500円、166,500円となる。

## 5. 図解で明示する注意点

- 計算結果に表示される「負担割合」は収入から求めた割合であり、食費には別に設定した割合が適用される。
- 支出額は端数処理のため、夫側を円単位で四捨五入し、妻側を予算合計との差額としている。これにより2人の支出合計は共通予算合計と一致する。
- 夫婦の合計収入が0円以下の場合は、割合・支出・残額をすべて0円として扱う。
- 片方の収入だけが0円の場合、収入がある側の負担割合は100%、もう片方は0%となる。
- 共通予算が合計収入を上回る場合も計算し、残額がマイナスになることがある。
- 共通予算の金額は計算ページ上で変更できる。食費項目がない場合は食費を0円として扱う。

## 6. 表示・操作の方針

- モバイルでは縦方向のステップ、広い画面では横方向のフローとして読めるようにする。画面幅に依存する図だけでなく、見出しと文章でも同じ流れを説明する。
- 色だけに意味を持たせず、各ステップに番号・ラベルを付ける。数式はテキストでも読める形にする。
- ライト・ダーク両テーマで既存ページと統一感のある表示にする。
- 各解説記事の末尾に解説一覧へ戻るリンクを置き、一覧ページから計算ページへ戻れるリンクを設ける。
- 数式と具体例は現在の実装・仕様解説書と一致させ、計算処理自体は複製・変更しない。

## 7. 実装時の確認項目

- `/explanation` が解説一覧を表示し、ヘッダーの「解説」リンクから遷移できること。
- 計算ロジック記事と家賃補助記事がそれぞれのパスで表示され、一覧から選択できること。
- 既存の家賃補助解説の内容が新しい記事ページへ引き継がれていること。
- 現行の `Calculator` の式、0円時の扱い、端数処理、食費の配分と説明が一致していること。
- 具体例の金額・割合が正しく、夫婦の支出合計が共通予算と一致していること。
- 解説一覧・各記事・計算ページ間の導線が適切に機能すること。
- レスポンシブ表示、ライト・ダークテーマ、アクセシブルな見出し構造を確認すること。
- 必要に応じてページ表示とヘッダーリンクのテストを追加すること。

## 8. 今回の検討対象外

- 計算式や家計負担の仕様変更
- 計算画面のレイアウト変更
- 家賃補助に関する既存解説の内容変更（一覧ページへの移設は対象に含む）
- 図解を画像として別途作成・管理すること
