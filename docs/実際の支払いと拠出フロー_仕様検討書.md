# 実際の支払いと拠出フロー 仕様検討書

## 1. 文書の位置づけ

家賃や光熱費などの共通支出を、夫婦それぞれのどちらの口座から実際に支払うかを可視化し、収入に応じた負担割合との差を調整する新規画面の仕様書です。

この文書は合意済みの仕様と実装前の確認事項を記載します。画面は `/cash-flow` として実装します。既存の家計負担割合計算画面の計算仕様を変更するものではありません。

## 2. 背景と目的

現在の計算画面は、共通予算の合計に夫婦それぞれの収入割合を適用して、目標となる負担額を表示します。一方、実際の家計では、家賃や光熱費などが一方の口座から引き落とされることがあります。そのため、画面上の負担額と、各自の口座から実際に出ていく金額が一致しない場合があります。

新規画面では、次の2つを分けて表示することを目指します。

1. **目標負担額**：従来どおり、収入に応じた負担割合から算出する金額
2. **実際の支払額**：各予算項目を、夫口座・妻口座・共通口座のどこから支払う設定かに基づく金額

この2つの差額を示し、どちらからどちらへいくら拠出・精算すれば、実際の負担が目標負担額に近づくかを調整できるようにします。

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 負担割合 | 夫婦それぞれの手取り収入が合計収入に占める割合 |
| 目標負担額 | 共通予算合計に負担割合を適用した金額 |
| 支払元 | 各予算項目の代金が実際に引き落とされる、夫口座・妻口座・共通口座のいずれか |
| 個人口座からの直接支払額 | 夫口座または妻口座を支払元に設定した項目の金額合計 |
| 夫婦間精算額 | 個人口座からの直接支払額が目標負担額を超えた場合に、超過分を調整するため夫婦間で移動する金額 |
| 共通口座入金額 | 個人口座からの直接払いと夫婦間精算を反映した後、共通口座へ入金する金額 |

## 4. 対象範囲

### 対象に含める

- 現在の手取り月収と共通予算を使って計算する。
- 予算項目ごとに、支払元を「夫口座」「妻口座」「共通口座」から選択できる。
- 各人の目標負担額、実際の支払額、差額を表示する。
- 個人口座からの直接払いと共通口座への入金額、必要な夫婦間精算額を表示する。
- 入力や支払元の変更に応じて、金額と図を即時更新する。
- 現在の計算画面・ボーナス計算画面とは独立した画面として追加する。
- 既存の計算画面と手取り収入・共通予算の入力状態を共有する。

### 対象外とする案

- 銀行口座への接続、口座番号・認証情報の取得、実際の振込や自動引き落とし。
- 銀行明細との照合、支払実績の自動取り込み。
- 夫婦間での合意や公平性そのものの判定。
- 収入比例以外の負担割合ルールの新設。

## 5. 合意した事項

1. 予算項目ごとに支払元を設定する。選択肢は「夫口座」「妻口座」「共通口座」の3つとする。
2. 共通口座への支出も初期版の対象とし、各自の共通口座への入金額を計算する。
3. 目標負担額から個人口座での直接払いを差し引き、残額を共通口座入金の計算に使う。直接払いが目標負担額を超過した場合は、負の入金額にせず、超過者が相手から受け取る精算額として表示する。精算後の共通口座入金額は0円以上とする。
4. 初期担当は画面上で夫または妻を選択し、全項目へ一括適用した後、項目ごとに変更できるようにする。共通口座へ支払う項目は個別に選択する。
5. 収入・共通予算の編集値は既存計算画面と新規画面の間で共有する。
6. 共有する編集値と支払元の選択は画面間の移動中に保持し、再読み込みまたはブラウザー終了後は初期値へ戻す。
7. 合計収入が0円の場合、新規画面では夫婦の目標負担額を50%ずつにする。既存計算画面の計算ルールは変更しない。
8. 共通口座の期首残高は扱わず、当月分の共通口座支出を当月の入金でまかなう。
9. 初期担当者を選んで全項目に適用した後は、各項目を夫口座・妻口座・共通口座のいずれかに必ず割り当てる。未設定の選択肢は設けない。
10. 共通口座への入金額と、個人口座からの直接払い後に必要な夫婦間精算額は別々に表示する。
11. 初期担当者の選択と一括適用操作は、共通予算の項目一覧の直前に置く。
12. フロー図の近くに「支払い前の共通口座入金」を表示し、その下に「直接払い後の夫婦間精算」を別枠で表示する。
13. 初期担当者を再選択して一括適用する場合は、全項目の支払元を上書きする。個別設定を上書きする可能性があるときは、実行前に確認する。

## 6. 画面構成

1. **収入と負担割合**
   夫婦それぞれの手取り月収、合計、負担割合を表示する。既存計算画面と入力値を共有する。

2. **支出と支払元**
   共通予算を項目別に一覧表示する。各項目の金額と支払元を確認・変更できるようにする。共通予算の項目・合計は既存画面と同じデータを使う。初期担当者を選んで一括適用した後、共通口座を含む支払元を項目ごとに調整できるようにする。

3. **お金の流れ**
   夫口座・妻口座・共通口座・支出項目を矢印でつなぐフロー図と金額一覧を表示する。夫婦それぞれの直接払い、共通口座への入金、共通口座からの支出を可視化する。実際の負担額と負担割合から求めた目標負担額の違いを、ラベルや金額でも区別する。色だけに意味を持たせない。

4. **拠出調整**
   フロー図の近くに「支払い前の共通口座入金」を表示し、その下に「直接払い後の夫婦間精算」を別枠で表示する。目標負担額を超えて個人口座から直接支払った人がいる場合は、送金元・送金先・金額を示す。

5. **負担後の残額**
   目標負担額を収入から差し引いた残額を表示する。必要に応じて、実際の支払額を差し引いた時点の手元残額も併記し、精算前後の違いを確認できるようにする。

## 7. 計算方法

### 7.1 目標負担額

既存画面と同じ収入比例の計算を用います。

収入額は月単位で扱います。合計収入が0円より大きい場合は、次のように既存画面と同じ収入比例で計算します。

```text
夫の負担割合 = 夫の手取り収入 ÷ 合計収入
妻の負担割合 = 妻の手取り収入 ÷ 合計収入
夫の目標負担額 = 共通予算合計 × 夫の負担割合（円単位で四捨五入）
妻の目標負担額 = 共通予算合計 - 夫の目標負担額
```

合計収入が0円の場合に限り、新規画面では夫婦の負担割合を各50%とし、夫の目標負担額を共通予算合計の半額（円単位で四捨五入）、妻の目標負担額を残額とします。既存計算画面の合計収入0円時の扱いは変更しません。

### 7.2 個人口座からの直接払いと共通口座支出

予算項目を支払元別に合計します。

```text
夫の直接支払額 = 支払元が夫口座である項目の金額合計
妻の直接支払額 = 支払元が妻口座である項目の金額合計
共通口座からの支出額 = 支払元が共通口座である項目の金額合計
```

### 7.3 精算額と共通口座への入金額

```text
夫の直接払い後残額 = 夫の目標負担額 - 夫の直接支払額
妻の直接払い後残額 = 妻の目標負担額 - 妻の直接支払額
```

期首残高を0円として扱うため、直接払い後残額の合計は当月の共通口座支出額と一致します。残額がマイナスの人がいる場合、その人は目標負担額を超えて直接払いをしています。もう一方からマイナス分を精算し、残った金額を共通口座への入金に充てます。精算を行う人の入金額は、精算額を差し引いた後の0円以上の額です。残額がどちらも0円以上の場合は、それぞれの残額を共通口座への入金額とします。

このルールにより、夫婦間の精算額を反映した後の各人の最終負担額は目標負担額と一致し、共通口座への入金合計は共通口座からの支出額と一致します。支払元が全項目に割り当てられていることを前提とします。

### 7.4 計算例

既存仕様書記載の共通予算299,000円、夫の収入240,000円、妻の収入210,000円を例にします。夫が家賃など90,000円を夫口座から直接払い、妻が日用品など20,000円を妻口座から直接払い、残り189,000円を共通口座から支払う設定とします。

| 項目 | 夫 | 妻 |
| --- | ---: | ---: |
| 負担割合（表示上の概数） | 53.3% | 46.7% |
| 目標負担額 | 159,467円 | 139,533円 |
| 個人口座からの直接払い | 90,000円 | 20,000円 |
| 共通口座への入金 | 69,467円 | 119,533円 |
| 最終負担額 | 159,467円 | 139,533円 |

共通口座への入金合計は189,000円となり、共通口座から支払う金額と一致します。

直接払いが目標負担額を超える場合の例として、夫が夫口座から200,000円を直接払い、妻の直接払いがなく、共通口座から99,000円を支払う設定を考えます。夫の直接払い後残額は-40,533円、妻は139,533円です。妻から夫へ40,533円を精算し、残る99,000円を妻が共通口座へ入金します。夫の最終負担額は159,467円、妻の最終負担額は139,533円となります。

## 8. 操作の流れ

1. 収入と共通予算を確認する。
2. 共通予算の一覧の直前で初期担当者を選び、全項目へ適用する。その後、必要に応じて支払元を「夫口座」「妻口座」「共通口座」へ個別に変更する。一括適用の再実行で個別設定を上書きする可能性がある場合は、事前確認を表示する。
3. 各人の直接支払額・共通口座入金額・目標負担額を比較する。
4. 表示された調整額を参考に、夫婦間の拠出・精算を検討する。
5. 支払元や予算額を変更し、調整結果を確認する。

画面が提示する金額は計算上の提案であり、実際に送金するかどうかは利用者が判断します。

## 9. 入力・例外時の扱い

- 収入・予算金額は0円未満を受け付けない。
- 初期担当者を全項目へ一括適用し、各項目には必ず支払元を設定する。
- 合計収入が0円の場合でも支払元と支払額を表示し、新規画面の目標負担額は夫婦で50%ずつとする。
- 片方の収入が0円の場合は、既存画面と同じく収入比例ではもう一方が100%負担となる。
- 予算金額または支払元を変更した場合、直接支払額・共通口座支出額・精算額・入金額を直ちに再計算する。

## 10. データ・画面連携

- 現在の共通予算マスタは `public/data/budget_data.csv` で管理され、列は `category`, `item`, `amount`, `is_active` です。支払元の選択は画面上の一時設定とし、CSVの形式は変更しません。
- 現在の計算画面での予算編集は表示中のみ有効です。新規画面の収入・金額・支払元も同様に一時的な編集とし、既存画面と画面間移動中の状態を共有します。再読み込み後の復元や永続保存は行いません。
- 口座名・口座番号などの金融情報は扱わず、支払元の区別は夫口座・妻口座・共通口座に限定します。

## 11. 仕様確定時の確認事項

- 夫婦間の精算を反映した後に、最終的な各人の負担額が目標負担額と一致すること。
- 端数処理を含めて、夫婦の目標負担額の合計が共通予算合計と一致すること。
- 全項目を割り当てた場合、実際の支払額合計が共通予算合計と一致すること。
- 送金元・送金先の表示が、直接払い後残額の正負と一貫していること。
- 収入合計が0円の場合、新規画面で50%ずつの目標負担額となり、既存画面の計算結果には影響しないこと。
- 収入0円、片方の収入0円、予算0円などのケースを確認すること。
- 既存の計算画面・ボーナス計算画面の動作と表示に影響を与えないこと。
