# アイデア帳

## 食費負担割合を個別に設定する

食費については、夫婦それぞれの必要カロリーなどの違いを考慮し、共通予算全体とは別の負担割合を設定できるようにする案がある。

### 検討案

- 食費負担割合の個別設定を、必要に応じて有効・無効に切り替える。
- 夫と妻の割合を入力できるようにし、2人の合計が常に100%になるようにする。
- 設定した割合を食費に適用し、食費以外の共通予算には従来どおり収入による負担割合を適用する。
- 食費に対するそれぞれの負担額も画面に表示する。
- 初期割合を夫55%、妻45%とする案があったが、再導入時に初期値や根拠を見直す。

この機能は現在の画面・計算から一旦取り除いている。再導入する場合は、設定の必要性や割合の初期値を改めて検討する。
